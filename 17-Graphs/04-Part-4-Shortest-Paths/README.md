# Shortest Paths

Choose based on edge weights and the problem:
- Unweighted graph: BFS
- Nonnegative weights: Dijkstra
- Negative weights: Bellman-Ford (also detects reachable negative cycles)
- All-pairs: Floyd-Warshall (practice)
