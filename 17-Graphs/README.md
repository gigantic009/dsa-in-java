# Graphs

Graphs are split into five parts.

## Part 1 — Representation
Vertices/edges, directed/undirected, weighted/unweighted; adjacency matrix, adjacency list and edge list.

## Part 2 — Traversal
BFS, DFS, connected components, path existence, grid traversal, flood fill and number of islands.

## Part 3 — Cycles and ordering
Cycle detection in directed/undirected graphs, bipartite graph, topological sort, Kahn's algorithm and course schedule.

## Part 4 — Shortest paths
BFS shortest path, Dijkstra, Bellman-Ford, Floyd-Warshall and path reconstruction.

## Part 5 — MST and advanced patterns
DSU with path compression/rank, Kruskal, Prim, bridges, articulation points and strongly connected components.

## Practice
Number of Islands; Clone Graph; Course Schedule; Rotting Oranges; Network Delay Time; Cheapest Flights Within K Stops; Redundant Connection; Min Cost to Connect All Points.
