# Graph Traversal

BFS uses a queue and explores level by level. DFS explores a branch and backtracks.

## Implemented
- [x] BFS — BFS.java
- [x] Recursive DFS — DFS.java

Both take O(V+E) time and O(V) auxiliary space for adjacency-list graphs.
