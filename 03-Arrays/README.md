# Arrays — A Complete Pattern-Based Learning Module

Arrays are contiguous indexed collections of elements of a fixed length in Java. Learn the foundations before moving to pattern problems.

## Prerequisites
Java variables, loops, methods, basic input/output and complexity fundamentals.

## Learning sequence
1. [Basics](01-Basics/README.md): declaration, initialization, indexing, traversal, min/max, reversal and common errors.
2. [Searching](02-Searching/README.md): linear search and binary search; understand sorted-input requirements.
3. [Two pointers and sliding window](03-Two-Pointers-and-Sliding-Window/README.md): pointer invariants, fixed and variable windows.
4. [Subarrays and prefix sum](04-Subarrays-and-Prefix-Sum/README.md): contiguous ranges, cumulative sums and Kadane's algorithm.
5. [Hashing and frequency](05-Hashing-and-Frequency/README.md): lookup, counting, duplicate detection and frequency maps.

## Essential concepts
- Array length vs valid indices (0 through length−1)
- Traversal and updating
- Copying vs aliasing references
- In-place vs extra-space solutions
- Searching and sorted-array assumptions
- Prefix sum and range calculations
- Two-pointer invariants
- Window expansion and shrinking
- Hashing tradeoffs

## Practice progression
Start with traversal and min/max, then reverse, search, frequency, sorted checks, rotations, prefix sums, two pointers, sliding windows and subarray problems. Don't jump straight to Hard.

## Every problem
Write the brute-force solution first when appropriate, explain why it works, improve it, test edge cases and state complexity. Consult the topic branch and question bank for the expanded practice inventory.
