# Arrays

The Arrays unit is organised by problem-solving pattern. Each problem should have a dedicated Java solution that reads from standard input.

## Subtopics

1. [Basics](01-Basics/README.md) — array traversal, min/max, reverse, products and fundamentals.
2. [Searching](02-Searching/README.md) — linear/binary search and variants.
3. [Two Pointers and Sliding Window](03-Two-Pointers-and-Sliding-Window/README.md) — two-pointer and window-based problems.
4. [Subarrays and Prefix Sum](04-Subarrays-and-Prefix-Sum/README.md) — Kadane, prefix sums and subarray problems.
5. [Hashing and Frequency](05-Hashing-and-Frequency/README.md) — duplicate detection, pair sums and frequency tracking.

## Completion rules

- A question is marked solved only when a corresponding Java implementation exists.
- Every Java `main` method must read input; no hardcoded example arrays.
- Each solution must include the complete problem statement, verified LeetCode number when available, company names when listed, and complexity.
- Similar questions with different requirements remain separate entries unless they are genuinely the same problem.
