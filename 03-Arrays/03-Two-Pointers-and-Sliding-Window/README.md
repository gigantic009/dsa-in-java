# Two Pointers and Sliding Window

## Learn
- Opposite-direction and same-direction two pointers.
- Slow/fast pointers in arrays.
- Fixed-size and variable-size windows.
- Maintaining a window invariant and moving boundaries.

## Practice questions
Two Sum in sorted array; 3Sum; Container With Most Water; remove duplicates; move zeroes; maximum sum subarray of size K; longest substring with constraints.
