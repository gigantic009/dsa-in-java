## Input format

Each program is run separately.

- **Contains Duplicate:** enter `n`, then `n` integers.
- **Given Sum Pair:** enter `n`, then `n` integers, then the target sum.
- **Repeat and Missing:** enter `n`, then `n` integers from 1 to n.
- **Duplicate N+1:** enter `n`, then `n + 1` integers in the range 1 to n.

All programs read from standard input. No sample array is hardcoded in `main`.
