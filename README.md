## Recommended study loop

1. **Understand:** Read the topic guide and identify the problem's inputs, outputs and constraints.
2. **Trace:** Dry-run a small example on paper.
3. **Attempt:** Write your own solution before opening the repository example.
4. **Test:** Try normal cases, boundaries, duplicates, empty inputs and invalid values where appropriate.
5. **Explain:** Describe the approach and why it works in your own words.
6. **Analyse:** Write time and auxiliary-space complexity.
7. **Revisit:** Re-solve after a day, a week and a month.

See the [Problem-Solving Guide](./PROBLEM-SOLVING-GUIDE.md) for a detailed workflow.

## Run Java examples

**Prerequisites:** JDK 17 or newer (Java 21 is also suitable), terminal, and an editor such as VS Code, IntelliJ IDEA Community or Eclipse.

```bash
java -version
javac -version
```

For a standalone source file, navigate to its directory and run:

```bash
javac Example.java
java Example
```

Replace `Example` with the class name. Some examples are online-judge style method solutions rather than standalone programs; read the source and topic guide first.
