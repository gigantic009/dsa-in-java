# Searching and Sorting

## Searching
Linear search, binary search, first/last occurrence, lower/upper bound, rotated sorted array and binary search on answer.

## Sorting
Bubble, selection, insertion, counting, merge and quick sort. Compare stability, in-place behaviour and best/average/worst complexity.

| Algorithm | Best | Average | Worst | Stable |
|---|---:|---:|---:|---|
| Bubble (optimised) | O(n) | O(n²) | O(n²) | Yes |
| Selection | O(n²) | O(n²) | O(n²) | No |
| Insertion | O(n) | O(n²) | O(n²) | Yes |
| Merge | O(n log n) | O(n log n) | O(n log n) | Yes |
| Quick | O(n log n) | O(n log n) | O(n²) | Usually no |
