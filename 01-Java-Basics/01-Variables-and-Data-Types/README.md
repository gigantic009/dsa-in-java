# Variables and Data Types

**Theory-only foundation.** This folder contains concepts, not interview problem files.

## Learn
- Variables, constants, identifiers and naming rules.
- Primitive types: byte, short, int, long, float, double, char and boolean.
- Reference types: arrays, String and objects.
- Declaration, initialisation, default values and scope.
- Type conversion, widening, narrowing and explicit casting.
- Integer overflow, floating-point precision and type promotion.
- Stack/heap overview and references at a beginner level.

## Quick notes
Java is statically typed: a variable has a declared type. Primitive variables hold primitive values; reference variables refer to objects or arrays. Choose a type based on the range and meaning of the data.
