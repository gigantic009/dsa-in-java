# Java Basics — Learn Java to Solve Problems

This module assumes no prior Java experience. Work through the chapters in order, write every example yourself, and complete the exercises before moving into DSA.

## Learning objectives
By the end, you should be able to write, compile, run and debug small Java programs; read input; choose types; use branches and loops; create methods; and understand the foundations needed to work with arrays, strings and objects.

## Chapters
1. [Variables and data types](01-Variables-and-Data-Types/README.md): values, types, declarations, conversions and overflow.
2. [Operators](02-Operators/README.md): arithmetic, comparison, logical, assignment and bitwise operators.
3. [Conditional statements](03-Conditional-Statements/README.md): if/else, switch and decision logic.
4. [Loops](04-Loops/README.md): for, while, do-while, break and continue.
5. [Functions and methods](05-Functions-and-Methods/README.md): parameters, return values, scope, reuse and method tracing.

## Recommended way to study
For every concept:
1. Read and explain the idea in your own words.
2. Type the examples yourself—don't copy/paste.
3. Trace the program with at least one normal and one boundary input.
4. Change the input or condition and predict the result before running.
5. Solve the practice prompts independently.
6. Debug deliberately: distinguish compile-time, runtime and logical errors.

## Essential additional practice before DSA
- **Input:** Scanner and BufferedReader; parse integers and strings safely.
- **Arrays:** create, initialize, traverse, update and pass to methods.
- **Strings:** immutability, character access, comparison and StringBuilder.
- **Classes:** fields, constructors, methods and object references.
- **Collections:** ArrayList, HashMap, HashSet, Queue, Deque and PriorityQueue.
- **Recursion:** base case, recursive case and call stack.

These concepts should be developed as lessons and practice rather than assumed. They are introduced in later topic folders and should be revisited alongside this foundation.

## Beginner checklist
- [ ] I can compile and run a Java program from the terminal.
- [ ] I can read integer, decimal and text input.
- [ ] I can explain primitive and reference types.
- [ ] I can predict arithmetic, comparison and logical expressions.
- [ ] I can write conditions and loops without copying.
- [ ] I can create, call and trace a method.
- [ ] I can work with arrays and strings.
- [ ] I understand what a class and object are.
- [ ] I can debug a simple compile-time, runtime and logical error.
- [ ] I can solve at least 25 small exercises independently.

## Practice prompts
Try these in increasing difficulty: print a greeting; convert Celsius to Fahrenheit; swap two variables; check even/odd; find the largest of three; make a simple grade calculator; sum numbers from 1 to n; print a multiplication table; factorial; prime check; write a reusable sum method; build a small menu using a loop and switch.

**Don't rush this module.** Strong Java fundamentals make every later algorithm easier.
