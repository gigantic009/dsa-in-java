# Java Basics — Learn Java to Solve Problems

This module assumes no prior Java experience. Work through each chapter in order, write every example yourself, and use the exercises before moving to DSA.

## Learning objectives
By the end, you should be able to write, compile, run and debug small Java programs; read input; choose types; use branches and loops; create methods; and work with arrays, strings and basic objects.

## Chapters
1. [Variables and data types](01-Variables-and-Data-Types/README.md): values, types, declarations, conversions and overflow.
2. [Operators](02-Operators/README.md): arithmetic, comparison, logical, assignment and bitwise operators.
3. [Conditional statements](03-Conditional-Statements/README.md): if/else, switch and decision logic.
4. [Loops](04-Loops/README.md): for, while, do-while, break and continue.
5. [Functions and methods](05-Functions-and-Methods/README.md): parameters, return values, scope, reuse and method tracing.

## Essential additional practice before DSA
- Input: Scanner and BufferedReader; parse integers and strings safely.
- Arrays: create, initialize, traverse, update and pass to methods.
- Strings: immutable String, character access, StringBuilder.
- Classes: fields, constructors, methods, object references.
- Collections: ArrayList, HashMap, HashSet, Queue, Deque and PriorityQueue.
- Recursion: base case, recursive case and call stack.

These concepts should be developed as lessons and practice rather than assumed. Some are currently introduced in later topic folders; they will be progressively integrated into this beginner sequence.

## Beginner checklist
- [ ] I can compile and run a Java program from the terminal.
- [ ] I can read integer, decimal and text input.
- [ ] I can write conditions and loops without copying.
- [ ] I can create and call a method.
- [ ] I can work with arrays and strings.
- [ ] I understand what a class and object are.
- [ ] I can debug a simple error.
- [ ] I can solve 25 small exercises independently.

**Don't rush this module.** Strong Java fundamentals make every later algorithm easier.
