# Matrix Fundamentals

## Implemented Java solutions
- [Transpose](TransposeMatrix.java) — rectangular matrix transpose.
- [Spiral Matrix](SpiralMatrix.java) — boundary-based traversal.
- [Rotate Image](RotateMatrix90.java) — in-place 90-degree clockwise rotation of a square matrix.

## Complexity checkpoints
- Transpose: O(rows × columns) time and O(rows × columns) extra space.
- Spiral traversal: O(rows × columns) time.
- Clockwise rotation: O(n²) time and O(1) extra space.
- Globally sorted matrix search: O(log(rows × columns)) time.
- Set Matrix Zeroes: O(rows × columns) time and O(1) auxiliary space.
