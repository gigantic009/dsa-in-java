# Cumulative DSA Exam Plan

Use these after the corresponding topic clusters. Each is a timed self-study test; solve without notes first, then review.

## Exam A — Foundations, Java and complexity (60 min)
Trace loops/methods, write pseudocode, analyze complexity, debug off-by-one/type/input issues. Implement min/max, counting, search and basic simulations.

## Exam B — Arrays, searching, sorting and matrices (90 min)
Two pointers, prefix sums, binary-search invariants, sorting trade-offs, matrix rotation/search, merge intervals, overflow and bounds. Include one proof and one test-design question.

## Exam C — Strings and bits (75 min)
Frequency maps, palindrome/window patterns, UTF-16/alphabet assumptions, masks, shifts and XOR. Include edge-case reasoning.

## Exam D — Recursion, lists, stacks and queues (90 min)
Trace recursive calls; reverse list; stack parsing/monotonic stack; circular queue and deque. Test empty/singleton and pointer boundaries.

## Exam E — Trees, BSTs, heaps and hashing (90 min)
Traversals, recursion-height analysis, BST validation, top-k and frequency patterns. Test skewed trees, duplicate policy and ties.

## Exam F — Graphs and greedy (120 min)
BFS/DFS, topological sort, shortest-path algorithm selection, DSU/MST and a greedy proof. Include disconnected, negative-weight and cycle cases where applicable.

## Exam G — Backtracking and DP (120 min)
State design, pruning, recurrence, base cases, memoization/tabulation, complexity and comparison to greedy. Include a trace and implementation.

## Exam H — Mixed interview simulation (120 min)
Four problems from different patterns. Score each with the rubric in [Mixed Interview Checkpoint](./INTERVIEW-MIXED-CHECKPOINT.md). Record mistakes, then re-solve at 1 day, 1 week and 1 month.

## Monthly report template
- Topics studied and problems independently solved.
- Problems solved without hints / with hints / after editorial.
- Most common error type: concept, invariant, coding, boundary, complexity or communication.
- Three weak topics and targeted next actions.
- Re-solutions due this month.
