# Mixed DSA Interview Checkpoint

**Time:** 90 minutes. **Rule:** no solution lookup until you have written an approach and attempted implementation. This is a self-study assessment.

## Part I — Pattern recognition (explain first)

1. Two Sum: explain brute force and hash-based trade-off.
2. Longest substring without repeated characters: explain window invariant and how shrinking restores validity.
3. Search in rotated sorted array: identify the sorted half in each iteration and invariant.
4. Valid parentheses: explain why stack, not a queue.
5. Level-order traversal: explain why BFS uses queue and its complexity.
6. Number of islands: explain visited-state and DFS/BFS complexity.
7. Coin Change: define state, recurrence, unreachable state and complexity.
8. Interval scheduling: explain the greedy choice and proof idea.
9. N-Queens: describe state, choices, conflict check and undo.
10. Range sum query with updates: describe a segment tree and its combine operation.

## Part II — Coding practice

Implement these independently in Java:

- Easy: reverse a linked list; binary search; valid parentheses.
- Medium: longest substring without repeats; merge intervals; level-order traversal; number of islands.
- Advanced: coin change; N-Queens; kth-largest using a heap; range-sum segment tree.

For every implementation, submit a trace, complexity, tests for empty/small/typical/boundary input, and state any assumptions.

## Part III — Interview communication rubric (10 points per problem)

- Clarifies constraints and assumptions: 1
- States brute-force baseline: 1
- Explains optimization and data structure: 2
- Gives invariant/recurrence/correctness reasoning: 2
- Code correctness and clarity: 2
- Edge-case tests: 1
- Time and auxiliary-space analysis: 1

## Review schedule

Review missed problems after 1 day, 1 week and 1 month. Re-solve without looking at the previous code. Record what pattern or invariant you missed.
