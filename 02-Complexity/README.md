# Time and Space Complexity

## Concepts
Operation counting; best/average/worst case; Big-O, Big-Ω and Big-Θ; O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ), O(n!); auxiliary space; recursion stack; in-place algorithms; loop and recursion analysis.

| Pattern | Typical time |
|---|---:|
| Fixed operations | O(1) |
| Repeatedly halve/double | O(log n) |
| One pass | O(n) |
| Efficient comparison sort | O(n log n) |
| Two full nested loops | O(n²) |
| All subsets | O(2ⁿ) |

Analyse a single loop, nested loops, doubling loop, linear vs binary search, recursive Fibonacci vs memoized Fibonacci, and auxiliary space of recursive array traversal. State what n means in every answer.
