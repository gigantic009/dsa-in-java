# Object-Oriented Programming in Java

## Sub-branches
- Class, object, state, behaviour and references.
- Constructors, constructor overloading, this and static.
- Encapsulation, access modifiers, getters/setters.
- Inheritance, super, overriding and final.
- Polymorphism: overloading and runtime overriding.
- Abstraction: abstract classes and interfaces.
- Composition versus inheritance and basic class design.

## Practice
Student class; BankAccount with deposit/withdraw validation; constructor overloading; Person/Student inheritance; runtime polymorphism; payment interface.
