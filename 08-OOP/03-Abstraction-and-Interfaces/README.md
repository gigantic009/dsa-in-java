# Abstraction and Interfaces

## Theory
Abstract classes, interfaces, implementation, multiple interface inheritance, abstraction and composition versus inheritance.


## Abstract class vs interface
An abstract class can hold instance state, define constructors and provide implemented methods alongside abstract methods. An interface describes a contract and allows a class to implement multiple interfaces. Choose based on the relationship and design requirements, not simply because one is shorter.
