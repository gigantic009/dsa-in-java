# Classes, Objects and Encapsulation

## Theory
Class/object, fields, methods, constructors, this, static, access modifiers, getters/setters and encapsulation. Theory-first section with small examples in notes.


## Key distinctions
- A class defines a type; an object is a concrete instance of that type.
- Instance fields belong to each object; static fields belong to the class.
- A constructor initializes state and has no return type.
- Encapsulation protects state: private fields plus operations that preserve invariants.
- Getters do not automatically imply setters should exist; expose only the operations the design needs.
