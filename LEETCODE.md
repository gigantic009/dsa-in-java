# LeetCode & Interview Problem Index

This index is a curated practice roadmap, not a claim that every listed problem has a repository solution. Exact IDs, official links, company tags, file paths, and test status are added only after verification. Problem names below are intended as topic targets; check the official platform listing before recording an ID.

## How to use this tracker
1. Attempt each problem independently before viewing a solution.
2. Record your attempt and review date.
3. When a solution exists in this repo, link its path.
4. Mark testing separately from understanding.
5. Use a revisit schedule; solved once is not mastery.

## Status definitions
- **Plan:** not attempted.
- **Attempted:** tried independently.
- **Understood:** studied a solution, not yet reproduced.
- **Reproduced:** solved independently and tested.
- **Mastered:** re-solved later and explained/solved a variation.
- **Repo verified:** solution file audited and test evidence recorded.
