# Backtracking Problem Patterns

## Implemented
- [Permutations.java](Permutations.java) — generate permutations (LeetCode 46; assumes distinct values for distinct outputs).
- [SubsetSum.java](SubsetSum.java) — enumerate subsets matching a target (basic subset-sum variant; repeated values can produce repeated subsets).

## Practice — Medium
- Phone keypad combinations (LeetCode 17)
- Word Search (LeetCode 79)
- Rat in a maze
- Restore IP addresses (LeetCode 93)

## Practice — Hard
- N-Queens II (LeetCode 52)
- Unique Paths III (LeetCode 980)
- Sudoku Solver (LeetCode 37)

## Pattern reminder
For each choice, update the state, recurse, and undo the update. Be clear about whether duplicate values should produce duplicate answers.
