# Backtracking

State-space tree, choose/explore/unchoose, pruning and duplicate handling.

## Sub-branches
Subsets; subsequences; permutations; combinations; combination sum; palindrome partitioning; rat in a maze; Sudoku; N-Queens.

## Practice
Subsets; permutations; combination sum; word search; palindrome partitioning; N-Queens.


## Sprint teaching expansion

Choose, recurse, undo. Maintain state invariant; prune only if no solution can remain. Practice subsets, permutations, combinations, N-Queens; test no-solution, duplicates, exponential cost.

Self-check: explain, trace, justify, implement, test boundaries and analyze complexity.
