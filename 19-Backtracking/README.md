# Backtracking

Backtracking explores a decision tree by **choosing, exploring, and undoing** choices. It is useful when a problem asks for all valid combinations, arrangements, or paths.

## Topic roadmap
Subsets; subsequences; permutations; combinations; combination sum; palindrome partitioning; rat in a maze; Sudoku; N-Queens; word search.

## Core template
1. Choose a valid option.
2. Recurse to explore.
3. Undo the choice so the next branch starts cleanly.
4. Prune only when a branch cannot lead to a valid answer.
