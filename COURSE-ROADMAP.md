# Complete DSA in Java Course Roadmap

This roadmap is designed for a student beginning in their first year and progressing to interview-ready problem solving. Each module is a milestone; prerequisite modules should not be skipped.

## Phase 0 — Thinking like a programmer
- What a program, algorithm, input, output and state are
- Breaking problems into smaller steps
- Pseudocode and flowcharts
- Dry-running and tracing
- Debugging and test-case design

**Checkpoint:** Solve 15 simple logic problems using pseudocode before Java.

## Phase 1 — Java for DSA
- Setup: JDK, IDE/editor, compile/run, command line
- Variables, primitive types, type conversion, expressions
- Input/output with Scanner and BufferedReader
- Operators and precedence
- if/else, switch
- for, while, do-while; break/continue
- Methods, parameters, return values, scope
- Arrays, strings, multidimensional arrays (intro)
- Basic classes, objects, constructors
- Recursion introduction
- Collections overview: ArrayList, HashMap, HashSet, Stack alternatives, Queue, PriorityQueue

**Checkpoint:** 30 small Java exercises and a mini CLI project.

## Phase 2 — Complexity
- What efficiency means; operation counting
- Big-O, Omega, Theta (conceptual distinction)
- Constant, logarithmic, linear, linearithmic, quadratic, exponential
- Best, average, worst case
- Space complexity and auxiliary space
- Recurrence basics
- Amortized analysis (intro)

**Checkpoint:** Analyse 20 snippets without guessing.

## Phase 3 — Arrays and problem patterns
- Traversal, min/max, reverse, rotation
- Linear and binary search foundations
- Frequency/counting
- Prefix sums and difference arrays
- Two pointers
- Sliding window (fixed and variable)
- Subarrays, Kadane
- Sorting applications
- Hashing and lookup
- In-place operations and tradeoffs

## Phase 4 — Searching and sorting
- Linear and binary search
- Binary-search variants and boundaries
- Binary search on answer
- Bubble, selection, insertion
- Merge sort, quicksort
- Counting/radix sorting (concepts)
- Stability, in-place, comparison lower bound
- Sorting-based patterns

## Phase 5 — Strings
- Character encoding basics and Java String immutability
- Character arrays and StringBuilder
- Frequency and hashing
- Palindromes
- Two pointers and sliding windows
- Pattern matching: naive, KMP and Z-function (advanced)
- Anagrams, subsequences, substring distinctions

## Phase 6 — 2D arrays and matrices
- Indexing, row/column traversal
- Matrix operations
- Search in sorted matrices
- Spiral traversal, transpose, rotation
- Prefix sums on matrices

## Phase 7 — Bit manipulation
- Binary representation and signed integers
- AND, OR, XOR, NOT, shifts
- Set/clear/toggle/check bit
- Counting bits
- Power-of-two patterns
- XOR tricks, masks and subset enumeration

## Phase 8 — Recursion and divide-and-conquer
- Call stack and base cases
- Recursion trees and stack tracing
- Recursion on arrays and strings
- Subsequences, subsets and permutations
- Backtracking vs plain recursion
- Divide-and-conquer
- Binary search, merge sort and quicksort recurrences

## Phase 9 — Linked lists
- Node and references
- Singly/doubly/circular lists
- Insert/delete/traverse
- Reverse, middle, cycle detection
- Merge, intersection and pointer patterns

## Phase 10 — Stacks and queues
- Stack abstraction and implementation
- Queue, circular queue and deque
- Linked-list and array implementations
- Parentheses and expression problems
- Monotonic stack/queue
- Next greater/smaller, histogram patterns

## Phase 11 — Backtracking
- State, choices, constraints, undo
- Subsets and combinations
- Permutations
- N-Queens
- Sudoku-style constraints
- Word search
- Pruning and complexity

## Phase 12 — Trees
- Terminology and representation
- Binary tree traversals
- DFS, BFS and level order
- Height, depth, diameter
- Path and subtree problems
- Tree construction and serialization concepts

## Phase 13 — Binary search trees
- BST invariant
- Search, insert, delete
- Min/max and predecessor/successor
- Validate BST
- Traversal-based patterns

## Phase 14 — Heaps and hashing
- Priority queues and binary heaps
- Heapify, insert, remove
- Top-K and k-way merge
- HashMap/HashSet internals (high-level)
- Collision, load factor, hashing caveats
- Frequency and grouping patterns

## Phase 15 — Greedy algorithms
- Greedy choice and proof intuition
- Interval scheduling
- Sorting by criteria
- Activity selection
- Job scheduling
- Huffman coding (concept)
- When greedy fails; compare DP

## Phase 16 — Graphs
- Graph terminology, directed/undirected, weighted
- Adjacency list/matrix
- BFS, DFS
- Connected components
- Cycle detection
- Topological sort
- Shortest paths: BFS, Dijkstra, Bellman-Ford
- MST: Prim and Kruskal
- Union-Find/DSU
- Bridges, articulation points and SCC (advanced)

## Phase 17 — Tries
- Trie node design
- Insert, search, prefix
- Word dictionary and wildcard concepts
- Trie-based backtracking

## Phase 18 — Dynamic programming
- Recognizing overlapping subproblems
- Memoization vs tabulation
- State, transition, base case
- 1D DP
- Grid DP
- Knapsack and subset-sum
- Subsequences and LIS
- Strings: LCS/edit distance
- Interval DP
- Tree DP and bitmask DP (advanced)

## Phase 19 — Range-query structures
- Segment tree
- Build, query, update
- Lazy propagation
- Fenwick tree (complementary advanced lesson)

## Phase 20 — Placement and competitive interview practice
- Mixed-topic problem solving
- Company-style patterns (with attribution caveats)
- Timed sessions
- Mock interviews
- Debugging and communication
- Portfolio and revision plans

## Mastery gates
A module is complete only after the student can:
1. Explain the core idea in their own words.
2. Trace an example without the code.
3. Implement from scratch.
4. Solve new problems beyond the tutorial examples.
5. Explain time and space complexity.
6. Pass the module checkpoint.
