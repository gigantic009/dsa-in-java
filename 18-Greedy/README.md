# Greedy Algorithms

Greedy algorithms make locally optimal choices. A greedy strategy is not automatically correct: establish why the choice is safe, often with an exchange argument.

## Topics
- Activity selection / interval scheduling
- Fractional knapsack (not 0/1 knapsack)
- Assign Cookies (LeetCode 455)
- Jump Game (LeetCode 55)
- Lemonade Change (LeetCode 860)
- Merge Intervals (LeetCode 56)
- Coin selection (greedy is not universally optimal)
