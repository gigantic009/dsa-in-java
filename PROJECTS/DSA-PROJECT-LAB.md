# DSA Project Lab — Java

These projects are designed to apply algorithms in small, demonstrable programs. Build progressively, document complexity and write tests. Do not use the project as a substitute for learning the underlying patterns.

## 1. Student Records Console (beginner)
**Concepts:** arrays, searching, sorting, OOP. **Features:** create/update/search students, average/grade report, sort by marks/name, validate input. **Acceptance:** no duplicate ID policy, empty dataset handling, tests, clear menus and README.

## 2. Task Scheduler (beginner/intermediate)
**Concepts:** queues, priority queues, sorting. **Features:** enqueue tasks, priority scheduling, due date, status transitions, simulate processing. **Acceptance:** stable tie-break, empty queue, priority behavior, unit tests.

## 3. Expression Calculator (intermediate)
**Concepts:** stacks, tokenization, precedence, parentheses. **Features:** arithmetic expressions, unary signs (optional), malformed-input diagnostics. **Acceptance:** test precedence, nested parentheses, divide-by-zero and malformed expression.

## 4. Contact Prefix Search (intermediate)
**Concepts:** HashMap and Trie. **Features:** add/delete/search contacts, prefix suggestions. **Acceptance:** duplicate policy, empty prefix, missing prefix and case policy documented.

## 5. Route Explorer (intermediate)
**Concepts:** graph adjacency list, BFS, DFS, shortest path. **Features:** route existence, unweighted shortest route, weighted route (non-negative weights). **Acceptance:** disconnected graph, isolated vertex, no route, edge validation.

## 6. Sudoku / N-Queens Solver (advanced)
**Concepts:** backtracking and pruning. **Features:** solve and report no solution. **Acceptance:** input validation, restore state correctly, tests for solvable and unsolvable puzzles.

## 7. Resource Planner (advanced)
**Concepts:** greedy versus DP. **Features:** compare a greedy baseline and DP for selected resource/coin constraints. **Acceptance:** explain where greedy fails, DP recurrence and complexity.

## 8. Range Analytics (advanced)
**Concepts:** segment trees. **Features:** update values and answer sum/min queries. **Acceptance:** range validation, brute-force differential tests and performance demonstration.

## 9. Algorithm Toolkit Capstone
Build a menu-based Java application that brings several modules together. Keep modules separated, tests automated, errors meaningful and README reproducible. Include sample inputs, complexity summary and known limitations.

## Definition of done for every project
- Scope and user stories documented.
- Algorithms and complexity documented.
- Input validation and edge cases.
- Automated tests and CI where practical.
- README with compile/run instructions and examples.
- No secret data, generated binaries or unrelated files in commits.
