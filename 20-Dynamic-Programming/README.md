# Dynamic Programming

DP is split into five parts. Derive recursion first, then memoize, tabulate and optimise space.

## Part 1 — Foundations
Overlapping subproblems, optimal substructure, state, transition, base case, memoization and tabulation.

## Part 2 — 1D DP
Fibonacci, climbing stairs, minimum cost stairs, house robber and decode ways.

## Part 3 — Grid DP
Unique paths, obstacles, minimum path sum, triangle and falling path.

## Part 4 — Subsequences and knapsack
0/1/unbounded knapsack, subset sum, equal partition, coin change, LIS and LCS.

## Part 5 — Strings, intervals and advanced
Edit distance, longest palindromic subsequence, matrix-chain multiplication, stock DP, DP on trees and bitmask DP.

## Practice
Climbing Stairs; House Robber; Coin Change; Unique Paths; Partition Equal Subset Sum; LIS; LCS; Edit Distance; Matrix Chain Multiplication.
