# Binary Search Trees

## Part B — Validation and advanced patterns
Validate with lower/upper bounds, LCA, kth smallest/largest, sorted array to balanced BST, recover swapped nodes and merge BSTs.

## Practice
Search/insert/delete; validate BST; kth smallest; LCA; convert sorted array to BST.
