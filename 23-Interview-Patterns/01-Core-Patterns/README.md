# Interview Patterns

Practice these problems by identifying the pattern, stating its precondition, explaining the invariant, and analyzing complexity.

## Easy
- [ ] Two pointers: pair sum in a sorted array — implemented here in `TwoSumSorted.java`
- [ ] Fast/slow pointers: cycle detection in a linked list

## Medium
- [ ] Sliding window: longest substring / subarray under a constraint
- [ ] Prefix sum + hash map: subarray sum equals K
- [ ] Binary search on answer: find the smallest/largest feasible value
- [ ] Monotonic stack: next greater element
- [ ] BFS: shortest path in an unweighted graph
- [ ] Backtracking: subsets and permutations
- [ ] Heap: top K elements
- [ ] Greedy: interval merging / scheduling

## Hard
- [ ] Minimum window substring
- [ ] Longest increasing subsequence (LIS)
- [ ] Advanced graph shortest-path patterns

## Study checklist
For each problem:
1. Clarify constraints and edge cases.
2. Describe a brute-force solution.
3. Identify the bottleneck and the pattern.
4. State and justify the invariant.
5. Implement and dry-run.
6. Test boundaries.
7. Analyze time and space complexity.

Avoid duplicate canonical solutions: link to the relevant topic implementation when one already exists.
